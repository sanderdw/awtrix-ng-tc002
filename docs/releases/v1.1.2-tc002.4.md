## What's new in v1.1.2-tc002.4

- **MP3s with album art play.** Songs with large embedded cover art stopped with
  *MP3 decoding failed* ([#12](https://github.com/sanderdw/awtrix-ng-tc002/issues/12)).
- **Upload songs with their normal names.** A file such as `Alyssa Reid - High.mp3` was refused
  with *Device not reachable*. It is now stored as `Alyssa_Reid_-_High.mp3` (at most 32
  characters).
- **The web UI stays responsive during an upload.** It no longer shows *Device not reachable*
  while a song is uploading.
- **Clear reasons when an upload is refused.** Files the clock cannot play, such as 22 or 24 kHz
  MPEG-2 audio (common for text-to-speech) or MP2, are refused with the reason and how to
  re-encode them. A song that does not fit tells you how much space is free.
- **Scripts can call strict web APIs**, such as Spotify's token endpoint
  ([#11](https://github.com/sanderdw/awtrix-ng-tc002/issues/11)). A script's own `Content-Type`
  header was sent twice.

Tested on a TC002: every change in a RAM trial, and all but the upload responsiveness fix in a
full install. The
[release validation protocol](https://github.com/sanderdw/awtrix-ng-tc002/blob/main/docs/VALIDATION.md)
has not been run on it, which is why it is a pre-release.

## If the clock does not start

First hold the knob while powering on: that starts the stock Ulanzi app, from which the installer's
`--restore` puts the stock firmware back. If even that fails, Ulanzi's own USB recovery
reinstalls the stock firmware:

1. Prepare a 16 GB USB drive and format it as FAT32.
2. Place the upgrade files and `zkautoupgrade` in the root directory of the USB drive.
3. With the base unit powered via the pin connector, power on the device, then insert the USB
   drive into the left-side USB-C port and wait for the device to restart and recover.
4. Once the device restarts and the "Ulanzi" logo appears, remove the USB drive. The device
   should return to normal.

More recovery options: [installation guide](https://github.com/sanderdw/awtrix-ng-tc002/blob/main/docs/INSTALL.md#if-the-clock-does-not-come-back).
