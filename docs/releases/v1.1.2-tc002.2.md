## What's new in v1.1.2-tc002.2

- **Knob turns over MQTT** ([#4](https://github.com/sanderdw/awtrix-ng-tc002/issues/4)). Every
  detent publishes `cw` or `ccw` to `<prefix>/state/knob` (not retained), also while block
  buttons is on, so the knob can drive Home Assistant, for example a soundbar's volume. Turning
  right is `cw`. With HA discovery on, the clock gains a **Knob** event entity. Every upstream
  MQTT topic is unchanged; see the
  [README](https://github.com/sanderdw/awtrix-ng-tc002#mqtt-compatibility) for an example
  automation.
- **Buy me a coffee** link for the port in the web UI and README. The upstream author's Ko-fi
  button stays first.
- The one-line installer now installs the newest **stable** release by default and takes
  `--version TAG` for a specific one.

Run on the test clock against EMQX 6.3.1 and Home Assistant. The
[release validation protocol](https://github.com/sanderdw/awtrix-ng-tc002/blob/main/docs/VALIDATION.md)
has not been run on this build, which is why it is a pre-release.
